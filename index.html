Mathematical Formulation

Cholesky Decomposition Algorithm: For a Symmetric Positive-Definite (SPD) matrix A in R^(n x n), compute lower triangular L such that A = L L^T: Diagonal Elements (j = 0 ... n-1): L[j][j] = sqrt( A[j][j] - sum_{k=0}^{j-1} L[j][k]^2 ) Off-Diagonal Elements (i = j+1 ... n-1): L[i][j] = ( A[i][j] - sum_{k=0}^{j-1} L[i][k] * L[j][k] ) / L[j][j] Linear System Solving (A x = b): 1. Forward Substitution: L y = b ==> y[i] = ( b[i] - sum_{k=0}^{i-1} L[i][k] * y[k] ) / L[i][i] 2. Back Substitution: L^T x = y ==> x[i] = ( y[i] - sum_{k=i+1}^{n-1} L[k][i] * x[k] ) / L[i][i]
